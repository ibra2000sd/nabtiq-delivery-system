# page-experience-composition
Produce a blueprint per page: section order, visual hierarchy, content density targets, responsive behaviour
per breakpoint, motion hierarchy (reduced-motion aware), and where each media slot sits. Inner pages get the
same care as the homepage. Feeds `art-direction-image-plan` and `web-implementation`.
