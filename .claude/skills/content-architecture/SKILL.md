# content-architecture
Produce `sitemap.json` + one `page-brief` per page. Each product/service brief MUST require the full essential-field
set (what_it_is, applications, sourcing_role, documented_origin, quality_indicators, packaging, trade_terms, logistics,
documentation, enquiry_requirements). A page with no purpose or no required facts is invalid.
