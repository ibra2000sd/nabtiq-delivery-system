# brand-strategy
Read the truth ledger. Produce `site-strategy.json` with: audience segments, positioning, value proposition,
differentiators (each tied to a `verified` or `owner-attested` claim), and **2–3 labelled Vision/Mission options**
marked `publication_mode: aspirational`. Never invent strategic facts; competitor claims are never transferred to
the client. The owner selects one option — publishing requires an owner approval event (see truth_ledger_lint).
